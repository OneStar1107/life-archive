### 2.2 自动化测试的平台限制（必须知道，否则会白忙）

| 限制 | 影响 | 应对 |
|---|---|---|
| App 端 **iOS 仅支持模拟器**跑 `uni-automator`，**不支持真机** | iOS 拿不到真机自动化数据 | iOS 走 **XCTest / XCUITest** + **TestFlight** 真实反馈补充 |
| **Windows 不支持运行 iOS 端用例** | 本机（Windows）跑不了 iOS 自动化 | 需要 macOS 环境或 CI 上配 macOS runner |
| 鸿蒙无云打包 | 鸿蒙无法用自动化流水线出包测试 | 必须**本地 DevEco Studio** 出包 + **AGC 云测试**兜底 |
| 鸿蒙单元测试用 `@ohos/hypium` + `hamock` | 与 Jest 体系不同 | 独立测试目录，见 06/07 号文件 |
