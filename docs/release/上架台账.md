# 上架台账

> **本文件的用途**
> 本文件是「人生档案」三端（iOS / Android / HarmonyOS NEXT）上架的**主台账**，是 `docs/prompts/08-三端上架发布.md` 第 ⑧ 节 **Definition of Done** 的交付物。
> 逐项记录：命名一致性、主体一致性、D1~D7 前置资质、各市场进度、包名与版本、隐私政策可访问性、`PrivacyInfo.xcprivacy`、鸿蒙四项一致、第三方 SDK 清单。
>
> **什么时候填**
> 1. **现在**：先把「通用前置资质 D1~D7」全部标为「未开始」并**立即启动办理**（证件周期可能 2 个月，是整个项目最长的一根关键路径）。
> 2. 每办完一项证件，回来把「状态」改为「已完成」并填「编号」。
> 3. 每次提交任一市场后，填该市场的提交日期、审核状态、驳回原因、整改记录。
> 4. 提审前走一遍第 ⑨ 节的总勾选。
>
> ⚠️ **本文件绝不记录任何密码、密钥、证书内容、AK/SK**，只记录"存放于 XXX"。
> ⚠️ **凡是还没拿到的真实信息，一律留 `TODO(待补充)`** —— 拿到后替换该占位即可，全局搜索 `TODO(待补充)` 可定位所有待填点。

### 3.1 D7 分支核对（确认走的是 `basic` 分支）

| 合规等级 | 需要的资质 | 本项目 |
|---|---|---|
| `basic` | 无需额外资质 | ✅ **适用** |
| `finance` | 《金融许可证》+《增值电信业务经营许可证》 | 不适用 |
| `health` | 《医疗机构执业许可证》 | 不适用。⚠️ 本应用的「身体信号」是**用户手动录入**，**不接入系统健康平台**，**不作医疗承诺**，故不属于 `health` 分支 |
| `news` | 《互联网新闻信息服务许可证》 | 不适用 |
| `ugc` | 内容安全评估报告 | 不适用。⚠️ 本应用是**单人自治**模型（无按 id 查询他人资料、无公开内容流），故不属于 UGC |
| `ai-gen` | 算法备案 + 生成合成内容标识 + 安全评估报告 | 不适用。⚠️ 洞察由**确定性规则**在用户数据上本地计算，**不接入大语言模型**，不生成合成内容 |

> ★ 上述判断依据可在代码中核实：后端 `insights.service.ts` 明确「洞察由离线分析任务写入，本服务只负责读」；前端无任何第三方 AI SDK。
