## 二、❌ 唯一阻塞项：项目根路径含中文

### 现状

| 位置 | 路径 | 问题 |
|---|---|---|
| 当前工作树 | `C:/Users/hyx11/WorkBuddy/Worktrees/人生档案APP开发/main-e001ba0f` | 含中文「人生档案APP开发」 |
| 主仓库 | `C:/Users/hyx11/OneDrive/桌面/人生档案APP开发/` | 含中文 **且** 位于 OneDrive 同步目录 |

### 为什么这是阻塞项

1. **鸿蒙编译链**（DevEco Studio + hvigor）对非 ASCII 路径支持不完整，典型症状是**编译能过但运行即崩**，日志里出现：
   ```
   cannot find record '&@dcloudio/uni-app-harmony/index&1.0.0'
   ```
   这种崩溃在真机日志里极难定位，会浪费大量时间。
2. **OneDrive 同步目录**会在编译期间锁定/替换文件，导致 hvigor 读取到半写入的 `oh-package.json5`，随机构建失败。
3. Android Gradle 与 iOS CocoaPods 在含中文路径下同样有已知问题。

### 整改方案（建议在进入阶段 06 真机出包前完成）

**目标路径**：`D:\hbuild\lifearchive`（纯 ASCII、无空格、总长 20 字符，远低于 255 上限）

**步骤**：

cd lifearchive

# 2. 从当前工作树推送未提交的改动后再克隆
#    （在当前工作树执行）
