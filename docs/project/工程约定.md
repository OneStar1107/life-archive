## 三、本地启动（三步）

### 0. 前置环境

| 工具 | 版本 | 说明 |
|---|---|---|
| Node.js | 20 LTS | 后端运行时 |
| pnpm | 9.x | `corepack enable && corepack prepare pnpm@9.12.0 --activate` |
| Docker Desktop | 24+ | 跑 PostgreSQL 16 + Redis 7 |
| HBuilderX | 4.61+ | 前端工具链 |
| DevEco Studio | 5.0.7.210+ | 仅鸿蒙真机调试需要 |

> ⚠️ **项目根路径必须纯 ASCII、无中文、无空格。**
> 当前工作树路径含中文，**鸿蒙编译会失败或发行后闪退**（Android / H5 不受影响）。
> 整改方案见 [`docs/project/工程红线自检.md`](工程红线自检.md)；
> Android 真机联调可先按 [`docs/release/android-device-runbook.md`](../release/android-device-runbook.md) 用 D 盘出包副本绕过。

### 1. 起数据库

```bash
cd backend
cp .env.example .env          # 填入本地开发值
cp .env.docker.example .env   # docker-compose 读取的变量
docker compose up -d
docker compose ps             # 期望：postgres healthcheck 转 healthy
```

### 2. 起后端

```bash
cd backend
pnpm install
pnpm prisma generate
pnpm prisma migrate deploy    # 建表
pnpm seed                     # 写入演示数据
pnpm start:dev                # 监听 :3000
```

打开 <http://localhost:3000/docs> 查看 Swagger。

**演示账号**（仅本地，`seed` 时打印）：`13800138000`

### 3. 起前端

用 HBuilderX 打开 `frontend/` 目录 → 运行到 Android / iOS / 鸿蒙模拟器。

后端地址由 `frontend/core/env/env.ts` 决定，开发模式指向 `http://127.0.0.1:3000`。
真机调试需改为你电脑的局域网 IP（**不要硬编码 IP 到页面里**，验完必须还原，见 PRD CH-006）。

## 四、日常命令

### 版本管理（唯一源 `frontend/version.json`）

```bash
node scripts/bump-version.mjs patch      # 1.0.0 → 1.0.1，versionCode +1
node scripts/bump-version.mjs minor      # 1.0.0 → 1.1.0
node scripts/bump-version.mjs major      # 1.0.0 → 2.0.0
node scripts/bump-version.mjs patch --dry-run   # 只看 diff 不写盘
```

> **只改 versionName 不改 versionCode 是华为与 Google Play 的明确驳回项。**
> 任何版本变更必须走这个脚本，禁止手改 `manifest.json` 与 `harmony-configs/`。

### 提交前门禁

```bash
node scripts/check-secrets.mjs        # 密钥泄漏扫描，命中即 exit 1
node scripts/check-error-codes.mjs    # 前后端错误码同源校验
cd backend && npx tsc --noEmit        # 类型检查
cd backend && pnpm test:e2e           # e2e（需数据库已启动）
cd frontend && pnpm test              # jest（105 条）
```

### 生成 API 契约

```bash
cd backend && pnpm gen:openapi
# 产出 docs/api/openapi.yaml 与 docs/api/error-codes.json
# 改了 Controller / DTO 后必须重跑
```

### 重新生成 App 图标

```bash
python scripts/gen-app-icons.py       # 依赖 Pillow；源图 frontend/static/app-icon-source.png
```

## 五、工程红线（每条都有检查手段）

| # | 红线 | 检查方式 |
|---|---|---|
| 1 | 根目录只有 `frontend/` `backend/` `docs/` `scripts/` + 根级配置 | `ls` 根目录 |
| 2 | **业务代码零平台宏** | `grep -rn "#ifdef" frontend/pages frontend/components frontend/stores` → 应为空 |
| 3 | 平台差异单一出口 | `grep -rln "#ifdef" frontend/` → 仅 `core/platform/index.ts` |
| 4 | 无硬编码宽高 / `100vh` | `grep -rn "100vh\|375px\|667px" --include="*.uvue" frontend/` → 应为空 |
| 5 | 仓库无真实密钥 | `node scripts/check-secrets.mjs` → 零告警 |
| 6 | 三端包名一致且符合鸿蒙规则 | 统一 `com.lifearchive.app` |
| 7 | 版本号单一源 | 走 `bump-version.mjs` |
| 8 | 前后端错误码同源 | `node scripts/check-error-codes.mjs` |
| 9 | 出参不泄漏内部字段 | e2e 用例断言 `deletedAt` / `passwordHash` 不出现 |

红线**检查结果**（哪项过哪项没过）记在 [`docs/project/工程红线自检.md`](工程红线自检.md)，本文件只放规范本身。

### 三个最容易踩的坑

1. **平台宏必须写 `APP-HARMONY`**，写成 `HARMONYOS` 编译不生效也不报错，
   安卓专属 API 会被打进鸿蒙包，运行即崩。
2. **鸿蒙没有云打包**，必须本地 DevEco Studio 出已签名 `.app`，用 `hdc install -r` 安装（**不是 adb**）。
3. **上架是证件活**：软著（约 30 工作日）+ ICP 备案（7~20）+ APP 备案（7~20）合计可能两个月。
   **开发第一天就要并行启动**，否则代码写完只能干等。
   倒排表见 [`docs/release/提审时间表.md`](../release/提审时间表.md)。

### uni-app x 特有暗雷（踩过才写在这里）

- **给 uni API 回调写内联对象类型 = 「H5 绿灯、Android 红灯」**：一律用官方全局类型名（PRD CH-008）。
- **uni API 失败是 reject Promise 不是同步 throw**：`setNavigationBarColor` / `navigateBack` / `switchTab` / `reLaunch` 要传 `fail` 回调。
- **`main.uts` 里 `createSSRApp` 第一次出现必须是真 import**：注释里先出现会吃掉 uni-h5-vite 入口的替换 → 每次冷启动报 Hydration mismatch。
- **`uni.getAppBaseInfo()` 无 `versionCode` 字段**（只有 `appVersionCode`），取值前做 typeof 守卫。

## 六、团队约定

- **提交信息**遵循 Conventional Commits：`feat: / fix: / chore: / docs: / refactor: / test:`
- **前端文件**大驼峰（`UserProfile.uvue`）；**后端文件**中划线小写（`user-profile.service.ts`）
- **数据库表名**复数下划线（`user_profiles`）；**字段**下划线小写
- **错误码**五位数字：`0` 成功 / `1xxxx` 参数 / `2xxxx` 认证 / `3xxxx` 权限 / `4xxxx` 资源 / `5xxxx` 业务 / `9xxxx` 系统
- **环境变量**全部大写下划线，经 Joi 校验，缺失即启动失败
- **业务文案**简体中文；**技术标识符**英文
- **禁止** `plus.*` API、`@tap` 事件、`100vh`、`position: fixed; bottom: 0` 裸写
- **禁止**在前端硬编码 baseURL 或完整 URL
- **禁止**在 `catch` 里吞掉错误（`catch(e) {}` 是零容忍）
- **证书实体一律存仓库外**（`D:\certs\`），仓库只同步配置结构
