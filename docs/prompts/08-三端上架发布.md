# 08 · 三端上架发布

> **投喂方式：`00` + `07`（已完成状态）+ 本文件。**
> 本文件按 `{目标市场}` 拆成四章，投喂时可只保留对应章节。

> ⚠️ **最重要的一件事**：上架不是技术活，**是证件活**。软著、APP 备案、ICP 备案的办理周期加起来可能长达 **2 个月**，必须在开发早期就并行启动，否则代码写完了只能干等。

---

## ① 角色设定

你是一位**应用商店合规与发布专家**，熟悉中国大陆 iOS + 安卓六市场 + 华为 AppGallery 的审核口径差异。你见过太多因为「软著名和桌面名差一个字」被驳回的案例。

## ② 目标与上下文

产出 `docs/release/上架台账.md`，并逐步完成 **{应用名称}**（包名 `{包名}`，主体 `{主体名称}`）在 `{目标市场}` 的上架。

## ③ 硬约束（命名一致性 —— 最高优先级）

```
{应用名称} 必须在以下四处完全一致，一字不差：
  ① 软著证书上的软件名称/简称
  ② 工信部 APP 备案的 APP 名称
  ③ App 桌面显示名
  ④ 各商店展示名（AGC / App Store / 各大安卓市场）

软著著作权人 == ICP 备案主体 == APP 备案主体 == 各商店开发者账号主体 == {主体名称}
```

不一致的后果：安卓全渠道驳回、App Store 备案编号填不进去、AGC 备案校验失败。

## ⑤ A 章 · Android 国内六市场

**A1 · 市场清单**：华为 AppGallery、小米、OPPO、vivo、腾讯应用宝、荣耀（覆盖 90%+ 国内量），另有三星、百度手机助手、360 手机助手可选。

**A2 · 开发者账号**：各市场**单独注册**企业开发者，认证费约 300 元/次。

**A3 · 签名**：`.jks` / `.keystore`，V1+V2(+V3)。**签名一旦确定不可更换**（换签 = 无法覆盖升级）。

**A4 · 素材**：图标 1024×1024 PNG（圆角无透明通道）；截图 3~5 张真实界面截图（备 16:9 与 18:9 两套）；简介 100~500 字；关键词。

**A5 · 各市场特殊要求**
- 华为：`targetSdkVersion ≥ 30`
- 小米：截图禁止出现竞品水印
- OPPO：包名有规范约束
- vivo：必须提供软著
- 应用宝：质量审核最严

**A6 · 审核周期**：华为 3~5 / 小米 2~4 / OPPO 3~5 / vivo 3~7 / 应用宝 5~7 工作日。

**A7 · Google Play（可选，按 `{目标市场}` 决定是否包含）**
- 唯一格式 **AAB**（新应用不再接受 APK）
- Play App Signing 强制
- **target API ≥ 35（Android 15）；2026-08-31 起新应用与更新须 ≥ API 36（Android 16）**
- Data Safety 表单（含第三方 SDK 的数据收集情况）
- IARC 内容分级；特色图片 1024×500
- 敏感权限需逐项声明用途
- **2023-11-13 之后创建的个人账号需 14 天封闭测试 + 至少 12 名测试者**才能上生产

## ⑥ B 章 · iOS App Store

**B1 · 账号**：Apple Developer Program，$99/年；企业账号另需 D-U-N-S 邓白氏编码。

**B2 · 证书**：Certificates / App ID / Provisioning Profile → 云打包或 Xcode 出 `.ipa`。

**B3 · 隐私清单（红线）**

**`PrivacyInfo.xcprivacy` 自 2024-05-01 起强制**，缺失或无效即被拒。至少声明 `NSPrivacyAccessedAPITypes`：

| API 类别 | reason code |
|---|---|
| UserDefaults | `CA92.1` |
| FileTimestamp | `C617.1` |
| DiskSpace | `7D9E.1` |
| SystemBootTime | — |
| ActiveKeyboard | — |

**第三方 SDK 也必须自带 manifest**（Firebase / Amplitude / Adjust / RevenueCat 等在 Apple 的 required-reason 名单内）。
提交前用 Xcode `Product > Generate Privacy Report` 校验。

**B4 · App Store Connect 填写**
- 隐私政策 URL + 支持 URL（必须可访问）
- App Privacy 营养标签（须与隐私清单、隐私政策一致）
- 若支持注册，**必须提供账号删除功能**
- 提供审核员**可用的演示账号**，且后端在审核期间必须在线

**B5 · 截图规格**：iPhone 6.9" → **1320×2868**；iPad 13" → **2064×2752**。真实截图，不可带 debug 信息。

**B6 · 工具要求**：Xcode 16+。

**B7 · TestFlight 先行**：外部测试需短审（通常 <24h），建议正式提交前先走一轮。

**B8 · 中国大陆专属**
- App Store Connect「App 信息」须填**工信部 ICP 备案编号**
- 简体中文 App 信息须与备案信息一致
- 游戏需 ISBN 版号；书报刊需《网络出版服务许可证》；宗教/新闻需对应许可证

**B9 · 驳回概率最高的两项**
1. **Guideline 2.1 App Completeness**（崩溃、占位内容、功能不全）—— 占未解决审核问题 40%+
2. **5.1.2 隐私**（隐私政策缺失、数据收集声明不符）

## ⑦ C 章 · HarmonyOS AppGallery

**C1 · 创建应用**：AGC「我的应用 → 新建应用」，包名必须与 `bundleName` **完全一致**。

**C2 · 申请发布证书**
DevEco `Build > Generate Key and CSR` → 得到 `.p12` + `.csr` → AGC「用户与访问 → 证书管理 → 新增证书（发布证书）」→ 下载 `.cer`。
> **每个账号最多 1 个发布证书。**

**C3 · 申请发布 Profile**
AGC「HarmonyOS 应用 → HAP Provision Profile 管理 → 添加（类型=发布）」→ 下载 `.p7b`（每应用最多 100 个）。
> 需 ACL 受限权限必须先向 `agconnect@huawei.com` 申请开通。

**C4 · 配置签名**
DevEco `File > Project Structure > Signing Configs`：**取消**「Automatically generate signature」，创建名为 **`release`** 的配置项，`signAlg` 固定 **`SHA256withECDSA`**。
同步 `build-profile.json5` 到 `harmony-configs/build-profile.json5`。

**C5 · 出包**：`Build > Build Hap(s)/APP(s) > Build APP(s)` → `.app`。
> **自签名不再被接受**，必须是 AGC 关联的发布证书。

**C6 · 上传**：AGC「版本信息 → 软件包管理 → 上传」→ 系统自动解析 versionCode / versionName / 设备类型 / 权限列表 → 点「启动自检」跑云测试。

**C7 · 包规范**：APP ≤ 4GB；`bundleName` 7~128 字符、点分 ≥3 段、禁保留字。

**C8 · 素材**：图标 216×216（需**分层图标**，前后景）；截图 ≥3 张（2340×1080 或 1080×2340）；**若适配折叠屏须额外提供折叠态截图**。

**C9 · 审核时效**：正式 1~3 工作日（多数 24h 内）；邀请测试约 3 小时；可在互动中心申请加急。

**C10 · 高频驳回清单（做成自查表，每次提审前逐条打勾）**

| # | 驳回项 | 自查 |
|---|---|---|
| 1 | 权限 `usedScene` / `reason` 缺失或理由笼统 | ☐ |
| 2 | 隐私政策缺失 / 不可访问 / 与权限声明不一致 | ☐ |
| 3 | 图标不一致（提交图标 ≠ 桌面图标 ≠ 最近任务图标）；未用分层图标 | ☐ |
| 4 | **versionCode 未递增** | ☐ |
| 5 | 功能不完整 / 含测试数据与测试入口 / 与系统自带应用重复 | ☐ |
| 6 | 截图与实际界面不符（不可用设计稿） | ☐ |
| 7 | 未适配平板 / 折叠屏；强制锁定屏幕方向 | ☐ |
| 8 | 冷启动超标、闪退率 >0.5%、内存峰值超标、后台耗电 | ☐ |
| 9 | 应用名与他人相同/相似、图标侵权 | ☐ |
| 10 | 广告无一键关闭按钮 | ☐ |
| 11 | **支持第三方账号登录时必须同时提供华为账号登录**（元服务必须用华为账号） | ☐ |
| 12 | APP 备案校验失败：名称/包名不一致、备案类型选错、主体错位、备案刚过需等 1 工作日再提交 | ☐ |

**C11 · 上架后搜不到怎么办**：需 HarmonyOS 5+ 设备；设备 API 版本在适配范围内；设备类型已发布；若设定了定时上架需等到时间。

## ⑨ 禁止事项

1. **禁止用不同的名字提交软著、备案和商店**
2. 禁止用個体/未认证主体提交需资质的品类（UGC/付费/社交）
3. 禁止把隐私政策做成 App 内文本或图片
4. 禁止在未取得备案号时提交 App Store 中国大陆
5. 禁止提交含测试数据、测试入口、调试开关的版本
6. 禁止用设计稿充当商店截图
7. 禁止 versionCode 不递增就提交
8. 禁止遗漏 `PrivacyInfo.xcprivacy`
9. 禁止遗漏任何一个第三方 SDK 的隐私披露
10. 禁止在隐私政策 URL 不可访问时提交审核
11. 禁止 App 首启在用户同意隐私政策前采集任何设备信息
12. 禁止忘记上架后 30 日内办理公安联网备案
