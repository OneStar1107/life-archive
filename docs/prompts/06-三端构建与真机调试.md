# 06 · 三端构建与真机调试

> **投喂方式：`00` + `03`+`04`+`05`（已完成状态）+ 本文件。**
> 前置：三端开发者账号已准备（账号办理见 08 号文件）。

> ⚠️ **三端最大的认知差异**：Android 与 iOS 可以**云打包**（Windows 也能出 iOS 的 ipa），但**鸿蒙没有云打包**，必须本地装 DevEco Studio 出包。这是最容易耽误工期的一点。

## ⑥ 分步任务

### A. Android

**A1 · 包名确认**：`manifest.json` → `app-plus.distribute.android.packagename` = `{包名}`。**一经发布不可更改**。

**A2 · 签名证书**

```bash
keytool -genkey -alias {别名} \
  -keyalg RSA -keysize 2048 -validity 36500 \
  -keystore {包名}.keystore
```

关键要求：
- **证书私钥密码必须与证书库密码一致**（HBuilderX 的硬性要求，不一致会报莫名的打包失败）
- 别名只用英文字母数字
- 有效期建议 36500 天（100 年），避免过期无法更新
- `.keystore` / `.jks` 文件**存到仓库外**（如 `D:\certs\`），密码写进 CI Secrets

> ⚠️ **签名一旦确定不可更换**。丢失或换签 = 用户无法覆盖升级 = 只能卸载重装，用户流失惨重。

**A3 · 云打包**：菜单「发行 → App-Android/iOS 云打包」，勾选 **V1 + V2（+V3）** 签名。

**A4 · 产物选择**
- 国内市场上架 → **APK**
- Google Play → **AAB**（HBuilderX 4.31+ 支持，勾选后渠道固定为 `google`）
- AAB **不能用 adb 直接安装**，需 bundletool 或走 Play 内部测试轨道

**A5 · 渠道包**：内置渠道 `huawei / oppo / vivo / xiaomi / honor / yyb`；自定义渠道写在 `manifest.json` 的 `__hbuilderx.channel_list`；运行时读取 `uni.getAppBaseInfo().channel`。

**A6 · 安装与调试**

```bash
adb devices
adb install -r app-release.apk
adb logcat | grep {包名}
```

**A7 · 调试基座**：标准基座包名是 `io.dcloud.uniappx`。若涉及原生模块或第三方 SDK，必须打**自定义基座**——**自定义基座严禁用于上架**。

### B. iOS

**B1 · Bundle ID**：`app-plus.distribute.ios.bundleid` = `{包名}`，设备类型至少勾选 iPhone 或 iPad 之一。

**B2 · 证书**：Apple Developer 后台申请 Distribution 证书（导出 `.p12`）+ Provisioning Profile（`.mobileprovision`）。

**B3 · 云打包**：Windows 环境只能云打包，产出 `.ipa`。

**B4 · 上传分发**：Transporter 或 Xcode Organizer 上传 → App Store Connect → **TestFlight**（内部测试 100 人即时生效；外部测试最多 1 万人，需短审，通常 <24h）。

**B5 · 真机验证**：TestFlight 安装最省事；也可通过描述文件信任方式安装 Ad Hoc 包。

### C. HarmonyOS NEXT（最容易出错，逐条核对）

**C1 · 环境**
- HBuilderX 4.61+ / DevEco Studio 5.0.7.210+（版本对应关系见 00 号③）
- 真机需 **API 14+**；模拟器镜像 **API ≥19**（建议 20+）
- Windows 开模拟器需专业版 + Hyper-V

**C2 · 路径**：项目根路径纯 ASCII、无中文、无空格；`frontend/.hbuilderx/launch.json` 已配置外置到 `D:/hbuild-dev`、`D:/hbuild-build`。
> 路径过长会导致编译失败，或更糟 —— **能发行成功但运行闪退**，崩溃日志里有 `cannot find record '&@dcloudio/uni-app-harmony/index&1.0.0'`。

**C3 · 调试证书**：HBuilderX 运行界面点击【配置调试证书】→【自动申请】（不含 ACL 权限）。
> 若用到受限权限（ACL），必须走 DevEco 手动申请。真机运行**必须签名**，模拟器不需要。

**C4 · 权限声明**（uni-app x 不会自动打包权限，必须手工维护）

`harmony-configs/entry/src/main/module.json5`：

```json5
{
  "module": {
    "requestPermissions": [
      {
        "name": "ohos.permission.CAMERA",
        "reason": "$string:camera_reason",
        "usedScene": { "abilities": ["EntryAbility"], "when": "inuse" }
      }
    ]
  }
}
```

_`user_grant` 类型的权限若缺 `reason` 或 `usedScene`，编译期即报 `The reason and usedScene attributes are mandatory for user_grant permissions`。_

`reason` 文案写在 `resources/base/element/string.json`，**必须具体到业务场景**：
- ✅「用于扫描二维码以快速添加好友」
- ❌「为了应用正常运行」（必被驳回）

**C5 · 构建发布包**
1. 先在 AGC 申请发布证书（`.cer`）与发布 Profile（`.p7b`），流程见 08 号 C2/C3
2. DevEco `File > Project Structure > Signing Configs`：**取消**「Automatically generate signature」，新建名为 **`release`** 的配置项，`signAlg` 固定 `SHA256withECDSA`
3. 同步 `build-profile.json5` 到 `frontend/harmony-configs/build-profile.json5`（调试项名 `default`，发布项名 `release`）
4. 菜单「发行 → App-Harmony-本地打包」→ 产出**已签名的 `.app`**
5. 若产出是未签名的，AGC 上传会失败（自签名不再被接受）

**C6 · 安装**

```bash
hdc list targets          # 列出设备
hdc shell bm get -u       # 查看设备 UDID
hdc install -r xxx.app
```

设备需开启开发者模式 + USB 调试 + 信任本机。

**C7 · 注意事项**
- ArkTS 热刷新需 HBuilderX 4.81+ / DevEco 5.1.1.823+
- release 模式**不支持断点调试与热更新**
- 升级 HBuilderX 后首次运行建议「清空缓存」

### D. 版本管理（每次发布必做）

```bash
node scripts/bump-version.mjs patch   # 或 minor / major
```

校验：三端 versionName 一致、versionCode 一致且严格大于上一版。**只改 versionName 不改 versionCode 是华为与 Google Play 的明确驳回项。**

## ⑦ 代码与命名规范

- 证书别名：`{应用英文名}Key`
- 证书文件命名：`{包名}.keystore` / `{包名}.p12` / `{包名}.cer` / `{包名}Release.p7b`
- 产物命名：`{应用英文名}-v{versionName}-b{versionCode}-{渠道}.{ext}`
- 版本号：`version.json` 唯一源，禁止手改 `manifest.json`

## ⑨ 禁止事项

1. **禁止把证书密码写进 `manifest.json` 或 `build-profile.json5`**
2. 禁止用 `adb` 安装鸿蒙包（必须用 `hdc`）
3. **禁止假设鸿蒙支持云打包**
4. 禁止用自定义调试基座提交上架
5. 禁止改了 versionName 却不改 versionCode
6. 禁止把证书文件提交进 git
7. 禁止在已上架后更换签名证书
8. 禁止把 AAB 直接 `adb install`
9. 禁止在 Windows 上用含中文的路径编译鸿蒙工程
10. 禁止跳过 `signing-ledger.md` 台账（证书丢了救不回来）
